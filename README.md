# KSS-Speedrun-Toolset
スパデラRTA用の総合ツールを目指してます（なんとこれ車輪の再発明）


## 起動方法
- KSS-Speedrun-Toolset.exe を実行してください。
- インストールや追加の画像・フォントファイルは不要です。
- Windows 11 x64 向けです。Windows 10 など他OSでの動作確認はしていません。


## 操作

### 全般
- カメラ、色、認識設定、その他乱数調整の設定は終了時に保存され、次回起動時に復元されます。
- 設定ファイルは %APPDATA%\KSS-Speedrun-Toolset\settings.json に保存されます。
- アプリ内の画像素材は実行ファイルに埋め込まれています。

### 銀河ウィンドウズ乱数調整
- テンキーの 1, 2, 3, 4, 6, 7, 8, 9 で星の方向を入力します。入力ガイドからの確認、入力が可能です。
- Backspace で1つ戻り、Enter で入力をリセットします。
- 画像認識は設定画面からカメラを選択し、開始を押して認識を始めます。テンキー5で画像認識の一時停止/再開が可能です。
